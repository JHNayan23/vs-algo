# 🧠 Algorithm Visualizer

A web-based tool that visually demonstrates how sorting algorithms work in real-time using HTML, CSS, and JavaScript. Built with the goal of making algorithm learning more interactive and engaging.

## 🔍 Features

- Visualize popular sorting algorithms:
  - Bubble Sort
  - Selection Sort
  - Insertion Sort
  - Merge Sort
  - Quick Sort
- Adjustable speed and array size
- Dynamic array generation with random values
- Responsive and user-friendly interface

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (Vanilla)
